# BTP — plateforme de devis assistés par IA

Projet SaaS pour les entreprises du bâtiment : préparation de devis à partir d’un cahier des charges et d’un catalogue privé, calcul déterministe et validation professionnelle.

## Dossier de conception

Le dossier contient **39 diagrammes rendus**, **26 règles métier**, **40 critères d’acceptation**, une matrice des permissions, un dictionnaire de **50 tables proposées**, un schéma SQL de référence et un ordre de développement distinguant MVP et extensions.

## Première version proposée

Le MVP se concentre sur les devis de peinture intérieure. Chantiers, portail client, avenants et planning sont modélisés comme extensions. Le métier pilote et les règles de chiffrage sont des décisions à valider.

Le projet est au stade de la conception. Les 17 contrôles SQL décrits portent sur le schéma proposé ; les tests de l’application et les commandes métier restent à implémenter.
